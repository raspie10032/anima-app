## 내장한 코어의 정확한 범위

SWEGCA Architecture의 Python evidence accumulator와 필요한 kernel/arbiter 정의를
원본 커밋과 라이선스·해시를 보존해 패키지에 넣었다. 임계값과 판정 알고리즘은 바꾸지 않았다.
검색과 명시적 평가 저장 경로에서 실제 호출하며, 같은 픽셀 쌍의 최신 평가를 재생하고
판정 영수증을 저장한다. 유사도 점수를 작가 신원이나 독립 증거로 취급하지 않는다.
이번 내장은 SWEGCA-bit의 C++ A/R/U 그래프 엔진 전체 이식을 뜻하지 않는다.
[정의·계약·알고리즘](EMBEDDED_VRS_CONTRACT.md).

## 실측

- 앱 자체 준비 경로에서 약 320 MiB의 비전 가중치를 받았으며 고정 해시를 확인했다.
- 기존 2,000장 모두 새 계약으로 색인: 409.15초, 실패 0건.
- 이전 2,000개 벡터와 새 벡터 비교: 최저 코사인 유사도 0.9999997992,
  평균 1.0000000511 (부동소수점 오차로 1을 약간 넘을 수 있음).
- 외부 VRS 프로젝트나 별도 Python 경로 없이 실제 CUDA 인코딩을 실행했다.
- 전체 회귀 1,146개 통과, 1개 건너뜀. 패키지 설치 후 내장 core import/실행과
  모델 미준비 상태, 설치한 GUI 자산·CLI 실행을 확인했다.

이 수치는 기능과 기존 벡터와의 연속성 검증이다. 새로운 화풍 검색 품질의 정답률은 아니다.
실측 산출물과 기존 DB 백업은 로컬 `outputs/embedded-vrs-20261015/`에만 보관한다.
원본 파일, 생성 기록, 기존 벡터를 삭제하거나 새 메타데이터로 덮어쓰지 않았다.
