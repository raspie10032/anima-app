# 画像生成ガイド — 日本語

[README](../README.md) · [한국어](IMAGE_GENERATION_KO.md) · [English](IMAGE_GENERATION_EN.md) · [技術リファレンス](APP_REFERENCE.md)

画面上部のアプリ言語を **日本語** に設定します。言語を切り替えてもプロンプトや生成条件は変わりません。このガイドでは、最初の1枚から別エンジンによる補正、比較、保存、類似例の再利用まで説明します。

## 1. 使う構成を選ぶ

| 構成 | 必要なもの |
|---|---|
| NAI で生成 | インターネット、利用可能な NovelAI アカウントとトークン。Anima のモデルは不要 |
| Anima で生成 | ローカルのチェックポイント、Qwen テキストエンコーダー、VAE、対応 GPU 環境 |
| NAI → Anima、または Anima → NAI のディテーラー | 両方の準備に加え、ローカル検出モデルとディテーラー用依存関係 |

NAI はリモートで実行します。ローカルの Anima モデルや LoRA を NAI の生成モデルとしてアップロードする機能ではありません。NAI ディテーラーでも領域検出はローカル処理です。

## 2. インストールと起動

Python 3.10 以降を使用し、完全なソースチェックアウトまたは source-checkout アーカイブを用意します。wheel 単体にはルートのローカル生成ランタイムが含まれません。GPU に適した PyTorch 環境も確認してください。

プロジェクトのルートで実行します。Linux / Bash:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
```

v0.6.1では **接続・準備 → NAIで生成 → NAIアクセストークン → トークンを適用** から入力します。再起動せず適用し、通常は実行PCの揮発性メモリだけに保持します。**このPCに保存（次回起動時も使用）**を選ぶとOSの資格情報ストアに保存して次回起動時に復元します。[ターミナル設定](NAI_TOKEN_SETUP.md)も使用できます。モデルと画像エンコーダーも同じ画面で準備します。[初期設定](../SETUP.md)。

```bash
python -m anima_app.cli serve --host 127.0.0.1 --port 8768 --open
```

下書きと表示言語を復元するには、次回も同じブラウザー・アドレス・ポートを使います。`--port 0` は空きポートを選びますが、保存先のオリジンが変わる場合があります。固定ポートが使用中なら既存サーバーを確認します。終了は処理完了後にターミナルで Ctrl+C を押します。

Anima とディテーラーを使う場合は、同じ Python 環境でモデルを準備します。

```bash
python -m anima_app.cli models copy-profile anima-t2i --source download
python -m anima_app.cli models copy-profile anima-aesthetic-v1.1 --source download
python -m pip install -e '.[face-detailer]'
python -m anima_app.cli models copy-profile face-detailer-detectors --source download
python -m anima_app.cli health --json
```

Aesthetic は任意です。基本プロファイルには共有エンコーダーと VAE が含まれます。ディテーラーを使うときは検出モデルと追加依存関係も必要です。上記はダウンロードを明示するため、空き容量を確認してください。既存ファイルを使う場合は[モデル参照](REFERENCES.md)のローカルコピー設定を利用できます。

## 3. 画面の配置

| 場所 | 用途 |
|---|---|
| 上部 | 生成/画像ワークスペースの切替、言語、最近の結果の表示切替 |
| 左側 | エンジン、プロンプト、サイズ、処理順、モデル・キャラクター・スタイル、参照と後処理 |
| 中央 | 結果、拡大、段階比較、条件と参照事例 |
| 右側 | 最近の結果と設定の復元 |
| 下部固定バー | 生成、停止、連続生成設定、進行状況 |

モデルやプリセットの詳細は折りたたみパネルを開きます。狭い画面では縦に並びます。

## 4. NAI で最初の1枚を作る

1. 生成エンジンで **NovelAI** を選び、下の状態表示を確認します。`/api/nai/status` の `configured` は値の設定確認であり、認証成功の保証ではありません。
2. 処理順で生成のみを選び、追加段階を空にします。従来の参照/後処理パネルのディテーラーも無効か確認します。生成のみボタンは追加段階を削除するもので、すべての既存機能を無効化するわけではありません。
3. モデル設定を開き、この例では **T2I / V4.5 Full** を選択します。
4. 最初は参照画像・ワイルドカード・キャラクタースロットを使わず、以下を入力します。

```text
1girl, adult woman, short brown hair, brown eyes, hairclip,
white blouse, portrait, garden, soft daylight, detailed eyes
```

ネガティブ例:

```text
blurry, low quality, extra fingers, text, watermark
```

5. **768×1024、28ステップ、CFG 6、Euler Ancestral、シード12345、1枚**を比較の出発点にします。全モデル共通の最適値ではありません。Medium Effort では14ステップなどの固定条件が適用されるため、画面の有効値を確認します。
6. Opus 無料範囲保護を維持して条件を確認します。アカウントや操作が対象外なら拒否されます。参照画像や Img2Img などで保護を解除すると Anlas が必要になる場合があります。事前検証の通過は請求の検証ではありません。
7. 段階別プロンプトのプレビューを開き、正/負の入力を確認します。プレビューでは画像を生成しません。
8. 生成を1回押し、待機・進行・完了表示を確認します。停止しても既に処理されたリモート要求や費用は取り消せません。
9. 最近の結果から画像を選び、モデル・シード・プロンプトを確認します。比較ではシードを固定して条件を一つずつ変えます。異なるモデルやバージョンでは同じシードでも同じ画像になりません。

## 5. Anima で生成する

1. ローカル Anima を選び、準備済みチェックポイントを指定します。
2. チェックポイントに加えてエンコーダー/VAE の準備状態を確認します。Aesthetic v1.1 があれば選択できます。
3. 同じ場面プロンプトで、既定の **832×1216 / 20ステップ / CFG 3.5 / euler_ancestral_cfg_pp / sgm_uniform** から始めます。
4. 追加段階と従来のアップスケール/ディテーラーを無効にして1枚生成します。
5. メモリが不足する場合は解像度・後処理・VRAM プロファイルを調整します。初回モデル読み込みと次の生成では所要時間が異なります。

## 6. 作家表記と重み

自動検出では `(artist:example_artist:0.9)` が NAI V4/V5 で `0.9::artist:example_artist ::`、Anima で `(@example_artist:0.9)` に変換されます。名前は説明用です。入力原文は編集欄に残ります。

- `artist:` または `@` があれば明示的な作家タグとして扱います。
- 接頭辞がない場合だけ、ローカル一覧と**タグ全体の完全一致**を確認します。文章の一部や未知の名前は推測しません。
- 作家順、グループの重み、括弧のエスケープを維持します。曖昧な構文は入力形式を指定し、警告を確認します。NAI V3 の重みは近似変換です。
- 作家一覧は同梱しません。必要なら `python scripts/update_artist_catalog.py --pages 20 --interval 2` で一部のアクティブタグを取得します。生成中のオンライン作家照会はありません。
- ワイルドカードの展開は別途プレビューします。実行時は展開後に変換するため、事前表示の未展開文と異なる場合があります。

## 7. NAI → Anima ディテーラー

1. 両エンジンと検出モデルを準備します。
2. 処理順で **NAI → Anima** を押します。先頭が NAI、次が Anima ディテーラーになります。この操作は既存の追加段階リストを置き換えます。
3. 最初の NAI 画像のモデル・プロンプト・シードを設定します。
4. 第2段階の条件を開き、Anima チェックポイントを選びます。補正 **10ステップ / 変更強度0.28** などから比較します。低い強度は元画像を残す方向ですが、モデルや領域で効果が変わります。
5. 最初のプロンプトを継承するか、継承を解除してこの段階専用の正/負プロンプトを入力します。
6. 検出方式・クロップ倍率・余白を確認し、段階別プレビューで NAI は `artist:`、Anima は `@` になっているか確認します。
7. 生成後、保存された NAI 出力が Anima に渡ります。段階比較で原本と補正後の目・表情・髪飾りを確認します。

## 8. Anima → NAI と長い処理順

1. **Anima → NAI** を押し、最初の Anima モデルと場面を設定します。
2. 第2段階で NAI モデル・ステップ・強度・CFG を選びます。変化が強すぎる場合は強度を下げます。
3. この段階の Opus 保護とクロップを確認します。全画像を覆うクロップや対象外条件は拒否される場合があります。倍率/余白を対象に合わせ、費用を理解してから保護を変更します。
4. 生成して Anima 原本と NAI 補正後を比較します。NAI 段階では対象領域がリモートサービスへ送信されます。

段階追加で Anima アップスケール/ディテーラー、NAI ディテーラーを選び、↑/↓で移動します。最初の生成/編集後に最大 **6段階**です。アップスケール後の顔補正と、顔補正後のアップスケールでは結果が異なります。方向ボタンは追加段階を置換し、従来パネルの後処理は先頭段階の表示でも確認できます。

## 9. 保存と画像からの再利用

現在の開発版はRS NAI 2.9.0のPNG・WebPから元画像の生成条件と領域別の補正履歴を分けて読み込みます。生成画面で画像の生成条件を読み込み、**適用する項目**を選択してください。サイズとシードのチェックを外すと現在値を保ちながらプロンプト・キャラクター位置を取り込めます。元画像の条件がない場合は顔のプロンプトを全体の条件として適用しません。

NAI補正ステップの**最初のステップのプロンプト・キャラクターを使用**で、Anima補正を挟んでもキャラクターと位置を引き継ぎます。**最初のNAIステップから引き継ぐ**ではモデルやサンプリング条件を個別に選べます。検出器の選択、PNG・WebP保存、応答タイムアウトも追加しました。[対応範囲と検証](NAI_NODE_UPDATE_2.9.0.md)を参照してください。これらは公開v0.6.1以降の開発変更です。

- 画像と中間結果は `outputs/images`、生成記録は `outputs/manifests`、処理順は `outputs/workflows` に保存します。
- プリセットに名前を付けると設定と段階順を保存できます。履歴の復元では入力原文と処理順を優先します。
- 下書きは同じブラウザー/アドレスに復元します。復元だけで生成は開始しません。プリセットにはモデルや参照画像本体は含まれないため、そのファイルも保持してください。
- 画像ワークスペースでフォルダーを取り込むかアプリ履歴を同期し、基準画像をドロップします。**総登録枚数に上限はありません。** ファイルを順次登録し、一覧はページ単位で読み込みます。
- 近い事例を選び、記録された作家構成・プロンプト・モデル・出典を確認します。入力画像にメタデータがなくても検索できます。類似性だけで実際の作者を判定する機能ではありません。
- 作家タグだけ、プロンプト、条件までの範囲を選んで下書きに取り込みます。編集/取り消し後に生成画面へ適用し、エンジン・保護・処理順を確認して明示的に生成します。
- 新しい結果の参照事例から元の正確な生成記録へ戻れます。比較評価は保存しますが、検索順位の自動学習はまだありません。
- CPU の色・配置・輪郭検索はそのまま使えます。VRS は[別途ローカルエンコーダーの設定](IMAGE_LIBRARY_EN.md)が必要です。

## 10. 問題が起きた場合

| 症状 | 確認すること |
|---|---|
| NAI 生成が無効 | 接続先、トークン状態、アップロード完了、入力エラー |
| トークン変更が反映されない | 新しい環境変数を設定したターミナルからサーバーを再起動 |
| 保護エラー | アカウント条件、操作、参照、サイズ、ステップ |
| Anima が未準備 | チェックポイント + エンコーダー + VAE、補正用検出モデルと依存関係 |
| 顔補正がスキップ | 対象検出の有無とマスクのプレビュー |
| 後段が失敗 | 完了済み出力と段階エラーを確認。停止後の自動再開や有料要求の自動再送はなし |
| VRS が使えない | 取込元、索引の完了、エンコーダー環境。CPU 検索でも確認 |
| 下書きがない | 同じプロファイル/アドレス/ポートか、保存領域を消していないか |
