# Anima APP v0.4.0 source-checkout beta

This release completes the long-running web usability and local-runtime safety pass while keeping Anima APP a source-checkout application.

## Highlights

- Route normal generation and Auto Queue through the same recoverable server queue, reconnect after browser refresh, and cancel waiting or running jobs without interrupting unrelated GPU work.
- Enforce bounded prompts, dimensions, pixels, sampling work, seeds, LoRAs, uploads, queue retention, and local-only HTTP trust before expensive decode or model work.
- Upload one reference image or LoRA through managed paths without exposing browser-local paths.
- Search and filter complete history before pagination, load bounded in-memory thumbnails, report managed storage usage, and retain explicit per-record deletion with rollback.
- Save canonical timestamped presets with malformed-file isolation, link rejection, prevalidated imports, rollback recovery copies, and schema-aware export.
- Make autocomplete resistant to stale responses, cursor movement, delimiters, and IME composition while preserving native textarea and keyboard behavior.
- Improve result alternatives, live status, reduced motion, pressed-state accuracy, and focus retention for dynamic controls.
- Publish a dependency-free OpenAPI 3.1 contract for local AI-agent discovery, generation, queue polling, cancellation, progress, and manifest retrieval.
- Include a detailed Korean guide for model preparation, GUI, CLI, AI-agent API flows, and troubleshooting.

## Release Integrity

- `anima_app.__version__` is the canonical package/application version and setuptools reads it dynamically.
- CI is configured to cover Python 3.10 and 3.13 on CPU, the Windows launcher, Python lint, JavaScript syntax, tests, vendored metadata, wheel boundaries, and the source candidate. Remote GitHub Actions execution is not claimed by this local release preparation.
- The wheel is built from a temporary source copy and proves that it does not contain the root-level vendored Comfy runtime.
- `scripts/source_archive.py --require-clean` reads committed Git content, fixes ZIP metadata, refuses private/runtime output trees and unresolved native binaries, verifies required files, runs extracted vendor/CLI smoke checks, and emits SHA-256.

## Provenance And License Boundary

- `vendor/anima_runtime` reports ComfyUI 0.22.2 and preserves GPL-3.0, but its exact upstream commit was not retained.
- The `comfy-aimdo` 0.3.0 base is disclosed as a patched Anima APP no-native shim with regenerated local `RECORD` hashes. Unused native allocator DLLs are excluded.
- `comfy-kitchen` 0.2.8 preserves Apache-2.0 license and notice files; an ignored local native extension is outside the release.
- Included wildcard text was copied or derived from ComfyUI Impact Pack under the observed GPL-3.0 license; its exact upstream revision was not retained.

## Distribution Boundary

The supported artifact is the digest-bound source-checkout ZIP generated by the release script. It includes application source, the disclosed vendored runtime, selected vendored Python source, the Windows launcher, public documentation including `docs/USER_GUIDE_KO.md`, notices, and wildcard text.

It excludes model checkpoints, detector weights, LoRAs, inputs, outputs, local configuration, Git history, and unresolved native binaries. The Python wheel remains a package/CLI verification artifact rather than a standalone generation bundle. Standalone binaries and public tag/release publication remain separate owner-controlled work.
